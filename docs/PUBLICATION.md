# Final release contents and rights

Version 1.0.0 contains research code, fixed configuration, input identifiers/hashes, bibliography records and aggregate scientific outputs. It excludes datasets, receiver observations, prepared feature rows, fitted models, full runtime traces, provider documents, correspondence, receipts, credentials and manuscript drafts. Both this checkout and its predecessor snapshots were checked for these excluded classes.

This release contains the audited IGASPIN 80/79 results and development 60/59 technical-repeat summaries. The public history was rebuilt as two cleaned release snapshots on 5 November 2026. Earlier public commit identifiers and archive checksums are superseded; the scientific implementation, fixed settings and aggregate results remain unchanged. The original research workspace and history backup are retained locally.

release/file_manifest.json binds current release files; publication_provenance.json identifies exported derivatives and the historical source identities. These are not replacement freezes. Personal paths are omitted; original hash identities are retained when useful, without implying access to excluded bytes.

RIGHTS.md states the current code-rights position. No general code reuse licence or third-party data licence is granted. Cite the original data providers separately; repository attribution cannot substitute for their terms. The exact development dataset-version/file binding and IGASPIN permission binding remain explicit unresolved items in the research record. No upstream archive or provider plot is redistributed.

The repository is public. The article manuscript and author-review notes remain separate. Reproduction documentation distinguishes data-free reconstruction, offline input preparation, scientific recomputation and newly measured hardware timing. No turnkey historical IGASPIN 80-run controller or full raw UBX timing is claimed.
